# 京成線・浅草線 トイレマップ

国府台から京成上野・大門（押上線・都営浅草線経由）までの各駅のトイレ情報をまとめた、スマホ向けの1ページサイトです。

- `index.html` 1ファイルで動きます（ビルド不要）。
- 駅データはページ内の `const S = {...}` にあります。
- わからない項目は推測で埋めず「未調査」のままにしています。

## 公開

https://keisei-toilet-map.pokapon.com/

VPS 上の Coolify で動かしています。`main` に push すると自動でデプロイされます（`Dockerfile` で nginx 配信、ポート 8080）。
